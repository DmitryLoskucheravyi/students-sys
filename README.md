# Be Smart School

Застосунок онлайн-школи: розклад, уроки, курси з роадмапом, абонементи, домашні. ШІ-режим розкладає текст програми на етапи роадмапа.

## Запуск

Потрібні Node.js 22+ і запущений MySQL. Доступ до бази задається в `.env` (приклад: `.env.example`).

```
npm install
npm run seed     # створює базу та демо-дані
npm run build
npm start        # http://127.0.0.1:3000
```

Для розробки: `npm run dev`, адреса http://localhost:5173.

Без демо-даних достатньо `npm run db:setup`: буде створено лише менеджера `manager / manager123`.

## Демо-входи

Лише для локальної бази. У проді пароль менеджера задає `INITIAL_MANAGER_PASSWORD`.

| Роль     | Логін     | Пароль       |
|----------|-----------|--------------|
| Менеджер | `manager` | `manager123` |
| Вчитель  | `teacher` | `teacher123` |
| Учень    | `student` | `student123` |

## Тести

```
npm run test:unit                 # без бази
npm run test:e2e                  # MySQL, браузер, окрема база bs_school_test
npm run test:e2e -- ai            # один набір із tests/e2e
npm test                          # усе разом зі збіркою
```

Для наскрізних тестів: `pip install -r tests/e2e/requirements.txt` і `python -m playwright install chromium`.
Тести не торкаються робочої бази, а Gemini в них підставний.

## Деплой

Інтерфейс на Vercel, API на Render, база й файли домашніх на TiDB Cloud. Покроково: [DEPLOY.md](DEPLOY.md).

## ШІ-режим

На сторінці курсу кнопка **Роадмап зі ШІ** приймає текст або файл `.txt` чи `.md`. Gemini повертає чернетку,
людина її виправляє, і лише тоді етапи записуються в курс. Потрібен `GEMINI_API_KEY`.

## Як усе пов'язано

- **Урок** — сутність: назва, вчитель, учні, курс, тривалість.
- **Розклад** — правило для уроку: постійно (дні тижня) або одноразово.
- **Заняття** — конкретна дата в календарі. Скасування і перенесення змінюють лише його.
- **Курс** — зміст і роадмап. Учень бачить курс, якщо є в уроці цього курсу.
- **Абонемент** — окремо від курсу. Вид задає кількість уроків і базову ціну, а виданий абонемент має власну ціну заняття.
- **Списання** — під час проведення заняття з абонемента присутнього учня. Ціна фіксується в момент списання, тому її зміна не торкається минулих занять.

Файли домашніх видаються лише автору, вчителю уроку та менеджеру. Локально вони лежать в `uploads/`, у проді стиснутими в базі.
