# SEO і видимість у ШІ: Be Smart School

Онлайн-школа програмування для дітей і підлітків. Основна ЦА — батьки. Формат: лише онлайн, без гео-сторінок.
Головна конверсія — заявка «Записатись» (пробне заняття безкоштовне).

## Як це влаштовано

Сайт — React SPA (Vite), не Next.js. Щоб боти бачили текст без JavaScript, сторінки рендеряться під час збірки:

| Файл | Що робить |
|---|---|
| `client/src/site/seo.js` | Мета сторінок, JSON-LD, slug курсів, FAQ, robots/sitemap/llms.txt. Чисті функції, тести в `tests/unit/seo.test.js` |
| `client/src/site/ssr.jsx` | Рендер тих самих компонентів у HTML (StaticRouter) |
| `scripts/prerender.mjs` | Після `vite build` пише `index.html`, `courses.html`, `courses/<slug>.html`, `prices.html`, `faq.html`… + `sitemap.xml`, `robots.txt`, `llms.txt`, `404.html`, `app.html` |
| `useSeo(meta)` у `parts.jsx` | У браузері оновлює `<head>` при переходах; під час збірки віддає мету пререндеру |
| `vercel.json` | Чисті адреси без `.html`; кабінет, `/q/*` і нові курси — `app.html` (noindex); решта — справжній 404 |

Дані (курси, ціни, відгуки, контакти) пререндер бере з `SITE_API` (у деплої — `vars.BACKEND_URL/api`).
Без `SITE_API` (локально, у тестах) сторінки збираються без даних, а браузер підтягує їх сам.
Якщо `SITE_API` задано, але API не відповідає, збірка падає: краще не задеплоїти, ніж віддати сайт без курсів.

**Новий курс, ціна чи відгук у кабінеті** людям видно одразу. У HTML для ботів і в sitemap вони з'являються після
наступного деплою. До того сторінка нового курсу працює як звичайна SPA, і Google її все одно бачить.

**Адреса курсу** — slug з назви напрямку (`HTML5&CSS3` → `/courses/html5-css3`). Якщо перейменувати напрямок,
адреса зміниться, тож назви напрямків краще не міняти без потреби. Старі адреси `/courses/3` переводять на slug.

## Аудит: що було і що зроблено

| Проблема | Було | Стало |
|---|---|---|
| Контент для ботів | Порожній `<div id="root">`: ШІ-боти не бачили нічого | Повний текст сторінок у HTML |
| robots.txt, sitemap.xml, llms.txt | Віддавали HTML головної | Справжні файли; ШІ-боти дозволені явно |
| Мета сторінок | Один title/description на весь сайт | Унікальні title, description, canonical, OG для кожної сторінки |
| H1 головної | Слоган без запиту | «Онлайн-школа програмування для дітей і підлітків 6+» (вигляд не змінився) |
| Адреси курсів | `/courses/3` | `/courses/java-script` |
| Структуровані дані | Немає | EducationalOrganization, WebSite, Course, ItemList, OfferCatalog, FAQPage, BreadcrumbList |
| 404 | Статус 200 (soft 404) | Статус 404, noindex, посилання на курси |
| Кабінет | Індексувався б | noindex + Disallow |
| OG-картинка | Немає | `/og.png` 1200×630 |
| FAQ для батьків | Немає | `/faq` + блок на головній |
| Політика конфіденційності | Немає (форма збирає ім'я й телефон) | `/privacy`, згода під формою |
| Перелінковка | Лише меню | Курси у футері, «Інші курси» на сторінці курсу, крихти |
| Соцмережі-заглушки | `<a href="#">` | Неактивні іконки без посилань |
| Порожня сторінка проєктів | Індексувалась | noindex, поки немає проєктів |
| IndexNow | Немає | Ключ на сайті, пінг після кожного деплою |

## Семантичне ядро і мапа «запит → сторінка»

Частотність не вигадана: її треба перевірити в Google Keyword Planner або Serpstat і далі в Search Console.
Один головний запит — одна сторінка (без канібалізації).

## Що зробити руками (код цього не зробить)

1. **Описи курсів у кабінеті** (Сайт → Напрямки → «Опис»). Зараз в усіх 7 напрямків опис порожній, і сайт
   складає його з тем програми. 2–3 речення: для якого віку, що дитина створить, з чого починати. Це найсильніший
   важіль для сторінок курсів.
2. **Контакти в кабінеті:**
   - email `besmart@school.com` схожий на заглушку (`school.com` — чужий домен). Вкажіть справжню пошту;
   - адреса «Chudnivska Street, 103-B» англійською і без міста. Для онлайн-школи її краще прибрати або
     написати українською повністю;
   - соцмережі порожні. Заповніть Instagram, TikTok, Facebook, Telegram: вони потрапляють у `sameAs`, і саме за
     ними пошуковики й ШІ впізнають школу як одну сутність.
3. **Власний домен** замість `besmart-edu.vercel.app`: потім задати `VITE_SITE_URL` у збірці (див. `seo.js`).
4. **Google Search Console і Bing Webmaster Tools:** підтвердити сайт кодом з HTML-тегу. Код покласти в змінні
   репозиторію `GOOGLE_SITE_VERIFICATION` і `BING_SITE_VERIFICATION` (Settings → Variables): тег з'явиться на
   головній після деплою. Далі надіслати `https://<сайт>/sitemap.xml` в обидва сервіси.
5. **Відгуки:** зараз один. Збирайте більше, з дозволу батьків, без прізвищ дітей.
6. **Проєкти учнів:** розділ порожній і тому закритий від індексації. Додайте 3–6 робіт, і він відкриється сам.
7. **Перевірити JSON-LD** у [Rich Results Test](https://search.google.com/test/rich-results) і
   [validator.schema.org](https://validator.schema.org) після деплою.
8. **Перевірити, що хостинг не блокує ШІ-ботів** (якщо колись з'явиться Cloudflare: «Block AI bots» вимкнути).
9. **Юридично перевірити `/privacy`:** текст описує, як реально працює система, але юрист має його підтвердити.

## Далі (за пріоритетом)

1. **Блог** `/blog/<slug>` зі статтями з кластера E: «Як обрати курси програмування для дитини», «З якого віку
   вчити програмуванню», «HTML чи Python: з чого почати», «Скільки коштують IT-курси для дітей». Кожна стаття:
   H2-питання з короткою відповіддю першим реченням, таблиця, FAQ, посилання на 2–3 курси.
2. **Сторінка «Про школу»** `/pro-nas`: рік заснування, засновник, викладачі з досвідом (E-E-A-T), методика.
3. **Аналітика** (GA4, подія `lead`) з банером згоди на cookies: зараз аналітики немає зовсім, і політика
   так і каже. Додавати разом з оновленням політики.
4. **Поле «вік дитини» у формі заявки**: допоможе і менеджеру, і звітам.
5. **Згадки поза сайтом:** каталоги IT-курсів для дітей, батьківські спільноти, YouTube з роботами учнів.
6. **Щомісяця:** нові запити з Search Console → розділи й статті; сторінки з CTR < 2% → переписати title і
   description; запитати в ChatGPT, Gemini, Perplexity і Claude «онлайн-школи програмування для дітей в Україні»
   і записати, чи згадується школа і які джерела цитуються.
